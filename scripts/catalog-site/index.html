Module Catalog

Schwung modules, built for Ableton Push 3 Standalone. Every one of them plays as a device in Live on the Push: install it from the Modules page of Pung.

Install

  1. Pung runs on your Push 3 Standalone (a Push Hack). Open its web page: http://<your push>:7720.
  2. Go to Modules, pick one, press Install. Pung checks the download and tests the module on the Push before it keeps it.
  3. Press Restart Live now: Live opens your Set again, and the module is in its browser under Pung.
  4. A module marked needs files (a ROM, a firmware dump) asks for them on its page in Pung. They are yours to add: no package here contains any.

Licences & source

Each module keeps its own licence. Every package carries its licence texts and a record of how it was built; the complete source of each build is published beside it (Source on its card): for GPL-licensed modules this is the Corresponding Source.
