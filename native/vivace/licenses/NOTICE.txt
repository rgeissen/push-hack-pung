Vivace: a Pung module (https://github.com/rgeissen/push-hack-pung, native/vivace)

Vivace's synthesis engine is built, unchanged, from the source code of an
open-source spectral warping wavetable synthesizer:

    https://github.com/mtytel/vital  (commit 636ca0ef517a4db087a6a08a6a8a5e704e21f836)

use the name or the logo. Its factory presets are not included: Vivace's
Factory bank is made by Vivace's own code (dsp/vivace_factory.cpp) and is
GPL-3.0-or-later like the rest.
