Vivace: a Pung module (https://github.com/rgeissen/push-hack-pung, native/vivace)

Vivace's synthesis engine is built, unchanged, from the source code of an
open-source spectral warping wavetable synthesizer:

    https://github.com/mtytel/vital  (commit 636ca0ef517a4db087a6a08a6a8a5e704e21f836)
    Copyright 2013-2022 Matt Tytel
    Licensed under the GNU General Public License, version 3 or later (LICENSE).

That synthesizer's name and logo are its author's trademarks. Vivace is not
that product, is not made, endorsed or supported by its author, and does not
use the name or the logo. Its factory presets are not included: Vivace's
Factory bank is made by Vivace's own code (dsp/vivace_factory.cpp) and is
GPL-3.0-or-later like the rest.

Vivace's own code (dsp/, tools/, push_ui.js): Copyright 2026 Pung
contributors, GPL-3.0-or-later. The complete corresponding source of this
package is the source archive the Pung catalog links for it.

The wavetable library (wavetables/) is built with the package by Vivace's
own code (dsp/vivace_wtbuild.cpp): 187 tables in 14 types. 43 of them are
computed by that code (GPL-3.0-or-later like the rest); the other 144 are
made from single-cycle waveforms of the Adventure Kid Waveforms collection
(AKWF-FREE), by Kristoffer Ekstrand, dedicated to the public domain under
CC0 1.0 (AKWF-CC0.txt):

    https://github.com/KristofferKarlAxelEkstrand/AKWF-FREE
    (commit 8de90bf94376670947369e69de0af6b9fbd19286)
