Install on a Push 3 · way 1, recommended

The Pung Installer

One program for your computer. It finds your Push on your network, asks the Push to let your computer in, installs Push Hack where the Push has none yet, then the newest Pung. Run it again after a Push software update: it puts back what the update took.

macOSApple silicon and Intel · macOS 11 or laterDownload WindowsWindows 10 and 11, 64-bitDownload Linuxx86-64Download

Pung Installer 0.1.0 · Linux on ARM 64: Pung-Installer-Linux-arm64.tar.gz · its source: installer/

  1. Open it. On macOS, unpack the zip and open Pung Installer. On Windows, unpack it and run pung-installer.exe. On Linux, unpack it and run ./pung-installer. Its window opens in your browser.

    The installer is not yet signed with a developer identity, so the first time your computer asks. On macOS: if it says the app cannot be checked, open System Settings › Privacy & Security and choose Open Anyway. On Windows: More info › Run anyway. A firewall such as LuLu asks once whether it may reach your network: allow it.

  2. Find your Push. It is on, in Standalone mode, on the same network as your computer; most networks know it as push.local.

  3. Let your computer in. Once: copy the key the installer shows, paste it on your Push's key page (push.local/ssh), and allow it on the Push with Shift + Select + Preferences. The installer goes on by itself.

  4. Install. It shows what it will do, and does it: Push Hack first where needed (the Push's own software restarts once then: save your Set), then Pung, with its progress. At the end it offers to restart Live, so Pung's devices appear in Push's browser.

Install on a Push 3

Through Push Hack

Pung runs on Push Hack, the open framework for community software on Push 3, and is in its catalog. Where Push Hack already runs:

  1. Open Push Hack Catalog in a browser: http://push.local:7702.
  2. Find Pung and choose Install.
  3. Restart Live once on the Push, so Pung's devices appear in Push's browser.

No Push Hack yet? Install it with the Push Hack Installer first, then follow the steps above, or let the Pung Installer do both.

Both ways leave the same Push: Push Hack, then Pung, as the catalog installs it. Updates arrive either way, on Pung's web page or in the catalog; see the manual.

No Push Hack yet? Install it first with the Push Hack Installer for macOS, Windows and Linux, then follow the steps above.

Updates arrive on Pung's web page and in the catalog; see the manual. Pung's own installer, which installs Push Hack and Pung in one go, arrives with the next release.

Before you start

What you need

  • An Ableton Push 3 in Standalone mode, on its newest Push software. Push Hack and Pung are put back after each Push software update.
  • Live started on the Push at least once.
  • A computer on the same network as the Push.
  • Firmware for the modules that emulate hardware (JE-8086, Mini-JV, Osirus, Nodal Red 2X, OsTIrus, Vavra, Xenia): yours, added on Pung's Modules page later. Pung never ships it.

Pung is not made, approved or supported by Ableton. Back up your Sets before installing anything on your Push.
